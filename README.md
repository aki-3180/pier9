# 第九埠頭

夜の埠頭で暴走ドローンを迎え撃つ、ブラウザで動く3D一人称シューティング。スマホ・iPad のタッチ操作と、パソコンのキーボード＋マウスに対応。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。3D ライブラリ three.js r128 と Web フォントを CDN から読み込むので、通信が必要です。

Vercel で公開する場合は、このリポジトリを Vercel に取り込み、Framework Preset を「Other」、Build Command と Output Directory を空のままにしてデプロイしてください（静的ファイルだけなのでビルドは不要です）。

| 操作 | タッチ | パソコン |
| --- | --- | --- |
| 移動 | 画面の左側をドラッグ | WASD |
| 視点 | 画面の右側をドラッグ | マウス |
| 射撃 | 射撃ボタン長押し | クリック |
| 狙う | 狙うボタン（押すたびに切り替え） | 右クリックを押している間 |
| 武器切替（ソロのみ） | 武器ボタン | 1〜5、Q、ホイール |
| 跳ぶ | 跳ぶボタン | スペース |
| 装填 | 装填ボタン | R |

- 木箱を足場にするとコンテナの屋根へ登れます。
- 外周の際まで歩けます。
- 狙うと視界が拡大し、弾のばらつきが減り、移動は少し遅くなります。SR はスコープ表示になります。
- SMG・AR・LMG・SG にはドットサイトが付いています。狙うと銃を目の高さまで持ち上げてサイトを覗き込み、画面の照準は消えて、ガラスに映る赤い点が狙点になります。点はばらつきの中心で、弾はその周りに散ります（狙ったときのばらつきは武器ごとに違います）。ソロでは、敵を捉えると点のまわりに輪が出ます。

| 武器 | 弾数 | 特徴 |
| --- | --- | --- |
| SMG | 36 | 連射が最速で足も速い。遠くでは威力が半分まで落ちる |
| AR | 30 | 標準。狙えばばらつきが3割まで減る |
| SR | 5 | 一発が重い。腰だめでは当たらないので、狙って撃つ。対戦では頭に当てると一撃 |
| LMG | 80 | 弾が多く撃ち続けられる。装填が長く、足が遅く、ばらつく |
| SG | 6 | 8粒の散弾。近距離専用。対戦では近ければ一撃（腰だめで 3m、狙えば 6m まで） |

武器ごとに弾倉は別々で、予備弾は無限です。弾のばらつきはソロと対戦で同じ値です（ソロではタッチ操作向けの狙いの補正が別に働きます）。
- 開始画面で、視点の感度（5段階）、ボタン配置（射撃・装填・跳ぶ・狙う・武器切替・移動スティックを画面の端まで好きな位置へドラッグ、ひとつずつ大きさを変更、左右入れ替え）、射撃中の視点操作（タッチのみ。切にすると射撃ボタンを押したまま指を動かしても視点が動かない）、オート射撃、効果音を変更できます。オンライン対戦では狙いの補正とオート射撃は働かず、弾は武器ごとのばらつきの範囲で照準へ飛び、相手の体（脚・胴・頭）に当たったときだけ命中になります。設定と自己最高得点は端末に保存されます。

## マップ

開始画面の「マップ」で選びます。自己最高得点はマップごとに別々に記録されます。

| マップ | 内容 |
| --- | --- |
| コンテナ場 | 60m 四方のコンテナヤード。木箱を足場にコンテナの上へ登れる |
| 倉庫街 | 南北に長い 54×78m。北と南の拠点を、3本の道（西＝倉庫の中、中央＝道路と管理棟、東＝岸壁）がつなぐ |
| 魚市場 | **昼のマップ**（ほかの3つは夜）。40×48m の小さなマップ。点対称（北側にあるものは、半回転した位置で南側にもある）なので、北と南のどちらから出ても条件は同じ。すぐ撃ち合いになる |
| 横丁 | **SG 向けのマップ**。夜の飲み屋横丁で、34×33m といちばん狭い。どこに立っても見通しが短く、角と扉がすぐ近くにある。魚市場と同じ点対称 |

倉庫街にあるもの：

- **倉庫（西）** … 南北のシャッター、道路側に扉2つと窓。中には木箱の山、フォークリフト、階段で上がれる中二階
- **管理棟（中央）** … 扉2つと窓3面の一室。外階段で屋上へ。屋上の縁は腰までの壁
- **引き込み線（中央と東の境）** … 有蓋車・平台車・タンク車。平台車は跳び乗れる。車両の切れ目が東西の通り道
- **岸壁（東）** … 燃料タンク、積んだコンテナ、船台に上げたイカ釣り漁船（木箱→木箱の山→甲板と登れる）、ガントリークレーンの脚、ポンプ小屋、消波ブロック
- **そのほか** … トレーラー、箱トラック、乗用車、土のう、コンクリート管、ドラム缶、仮設事務所、自動販売機、金網フェンス

魚市場にあるもの：

- **競り場（中央）** … 三段上がる台。上に木箱、頭上に屋根。屋根があるので二階の窓からは台の上が見えない
- **製氷棟（北西）と漁協（南東）** … 同じ間取りの二階建て。一階は扉3つ（北・南・競り場側）、奥の壁沿いの階段で二階へ。二階は競り場を見下ろす窓と、飛び降りられる荷揚げ口
- **建物の向かいの空き地** … 弾が通る網干しの柵、コンテナと木箱、ドラム缶
- **中央線上のコンテナ（東西の端）** … 木箱から登れる
- **拠点（北と南）** … 保冷車（車体の下を弾が通る）、発泡箱の山、漁網

横丁にあるもの：

- **居酒屋（中央）** … 東西南北に扉が1つずつ。扉の前は袖壁で囲ってあり、正面からしか見えない。中は厨房を囲むカウンターで、厨房が邪魔をして扉から向かいの扉は見通せない
- **立ち飲み（北西）と角打ち（南東）** … 通り抜けられる店。外周の通り側と内側の通り側に扉が1つずつ
- **内側の通り** … 居酒屋をぐるりと囲む幅 3m の道。提灯が下がっている。このマップでいちばん長く見通せるのはここ（15m ほど）
- **広い路地（幅 4m）と細い路地（幅 2m）** … 外周の通りと内側の通りをつなぐ。各辺に1本ずつ。細い路地は居酒屋の壁に突き当たる
- **外周の通り** … 幅 4m。対戦の出撃地点はここ（四隅と各辺の中ほど）
- **衝立（屋台・酒樽の山・自販機・板塀）** … 高さ 3m。外周の通りと広い路地を、左右から2つ1組で互い違いにふさいでいる。隙間（1.8m）を回り込んで抜ける。向こうは見えず、弾も通らない

横丁の見通しの短さ（立てる場所どうしで「相手が見える」組み合わせを全部数えたもの）：

| マップ | 見える相手までの距離（中央値） | 7m 以内の割合 | いちばん長い見通し |
| --- | --- | --- | --- |
| コンテナ場 | 20m | 11% | 79m |
| 倉庫街 | 20m | 11% | 84m |
| 魚市場 | 18m | 13% | 58m |
| 横丁 | 4m | 82% | 16m |

SG の散弾が威力を保つのは 7m までなので、横丁ではほとんどの撃ち合いが SG の届く距離で起こります。対戦では一粒 13（8粒すべて胴に当てて 104）なので、近ければ一撃です。一撃になる割合は、腰だめで 3m まではほぼ確実、4m で約半分、5m で約1割。狙えば 6m までほぼ確実、7m で約半分です。その先は急に弱くなり、8m を超えると AR に撃ち負けます。

知っておくと役に立つこと：

- 階段は歩くだけで上がれます（跳ぶ必要なし）。
- トレーラー・トラック・貨車・漁船は、車体の下の隙間を弾が通ります。足元は撃たれます。
- 金網フェンスは通り抜けられませんが、弾は通ります。
- 窓は撃ち合えますが、通り抜けはできません。扉や天井の下では、跳んでも頭がつかえます。
- ソロでは、偵察機と突撃機は倉庫のシャッターから中へ入ってきます。重装機と管理棟の中は入れません（窓と扉越しに撃ってきます）。ドローンは北・南・海（東）から現れます。
- 横丁には登れる高い場所がありません。乗れるのはカウンター、ベンチ、ビールケース、植え込みまでで、衝立や屋根には上がれません。
- ソロの横丁では、ドローンは外周の通りに降りてきます。偵察機と突撃機は衝立の隙間を抜け、重装機は衝立の上を越えます。居酒屋と立ち飲みの中まで入ってくるのは突撃機だけです。
- ソロの第20波には統括機（ボス）が出ます。壁より高いところを飛び、5連射し、8秒ごとに突撃機を2機放ちます。体力が半分を切ると連射の間隔が詰まります。倒すと必ず回復が落ち、第21波以降も続きます。その先は5波ごと（25、30、35…）に、少しずつ硬くなった統括機が出ます（体力は第25波で1.25倍、第30波で1.5倍）。
- アドレスの末尾に `?wave=20` を付けると、その波から始められます（ボスだけ試したいとき用）。

## オンライン対戦

同じ「部屋コード」を入れた人同士で撃ち合う個人戦です。通信には [Supabase](https://supabase.com) の Realtime（無料枠あり）を使います。設定しなくてもソロは遊べます。

### 設定

1. Supabase でアカウントを作り、新しいプロジェクトを作る（データベースのテーブルは不要）
2. プロジェクトの Settings → API を開き、「Project URL」と「anon（publishable）key」を控える
3. `config.js` の `url` と `key` に貼り付けて、コミットしてプッシュする

```js
window.PIER9_NET = {
  url: 'https://xxxxxxxx.supabase.co',
  key: 'ここに anon / publishable key'
};
```

この2つはブラウザに配る前提の公開値です。**`service_role` キーは絶対に入れないでください。**

### 対戦のしかた

1. 開始画面で名前を入れる（10文字まで・必須。端末に保存されます）
2. 「招待リンクをコピー」で、部屋コード入りの URL を相手に送る
3. お互いに「オンライン対戦」を押す

プレイ中は、誰が誰を倒したかが画面左上に名前で流れます。自分が倒したとき・倒されたときの表示も名前で出ます。

体力の下に順位表が常に出ます。撃破数の多い順（同数なら被撃破の少ない順）に、順位・色・名前・撃破・被撃破が並び、自分の行は明るく表示されます。画面の低いスマホでは4行まで（自分が圏外でも最後の行に自分が出ます）、それ以外は8行まで。一時停止すると全員分の表が出ます。

対戦では武器は一丁だけです。開始時に選び、倒されたら復帰までの3秒のあいだに選び直せます（選ばなければ同じ武器。パソコンは 1〜5 キー）。戦闘中の武器切替はできません。

部屋コードは、戦闘中に右上の一時停止ボタンを押すと表示され、そこから招待リンクもコピーできます。

チャットは、右上の「会話」ボタン（パソコンは Enter か T）で入力欄を開き、40文字までの文を送れます。同じ部屋の全員の画面左上に名前つきで表示され、約9秒で消えます。連続送信は1秒に1通までです。

マップは部屋ごとに1つです。先に部屋にいた人のマップに、後から入った人が自動でそろいます（同時に入った場合はどちらか一方にそろいます）。変えたいときは全員が対戦をやめて、選び直した人から入り直してください。

倒されると3秒後に別の場所で復帰します。レーダーに相手が映るのは発砲直後だけです。

### 知っておくこと

- 当たり判定は撃った側の端末が行い、撃たれた側がそれを信じる方式です。不正対策はないので、知り合い同士で遊ぶ前提です。
- 部屋コードを知っていれば誰でもその部屋に入れます。
- チャットは保存されず、暗号化や内容のチェックもありません。部屋コードを知っている人なら誰でも読めます。
- 公開キーはページのソースから誰でも読めます。第三者がこのキーで Realtime の無料枠を消費することは防げません。
- 1人あたり毎秒およそ10通を送ります。Supabase 無料枠の目安（同時接続200、毎秒100通）だと、同時に遊べるのは全部屋あわせて8人前後までです。
