# 第九埠頭

夜の埠頭で暴走ドローンを迎え撃つ、ブラウザで動く3D一人称シューティング。スマホ・iPad のタッチ操作と、パソコンのキーボード＋マウスに対応。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。3D ライブラリ three.js r128 と Web フォントを CDN から読み込むので、通信が必要です。

Vercel で公開する場合は、このリポジトリを Vercel に取り込み、Framework Preset を「Other」、Build Command と Output Directory を空のままにしてデプロイしてください（静的ファイルだけなのでビルドは不要です）。

| 操作 | タッチ | パソコン |
| --- | --- | --- |
| 移動 | 画面の左側をドラッグ | WASD |
| 視点 | 画面の右側をドラッグ | マウス |
| 射撃 | 射撃ボタン長押し | クリック |
| 狙う | 狙うボタン（押すたびに切り替え） | 右クリックを押している間 |
| 武器切替（ソロと協力） | 武器枠1〜5のボタンを押す | 1〜5（枠の番号）、Q、ホイール（枠の順） |
| 跳ぶ | 跳ぶボタン | スペース |
| 装填 | 装填ボタン | R |

- 木箱を足場にするとコンテナの屋根へ登れます。
- 外周の際まで歩けます。
- 狙うと視界が拡大し、弾のばらつきが減り、移動は少し遅くなります。SR はスコープ表示になります。
- SMG・AR・LMG・SG にはドットサイトが付いています。狙うと銃を目の高さまで持ち上げてサイトを覗き込み、画面の照準は消えて、ガラスに映る赤い点が狙点になります。点はばらつきの中心で、弾はその周りに散ります（狙ったときのばらつきは武器ごとに違います）。点のまわりには何も出ません（敵を捉えても輪は出ません）。
- 弾が当たると、当たった場所にダメージの数字が浮かびます。同じ相手に 0.5 秒以内に続けて当てた分は1つの数字に足されていくので、連射は増えていく1つの数字に、SG の8粒は合計1つの数字になります。頭に当たった分が入ると金色になります。数字の濃さは設定の「ダメージ数字」で 切・25%・50%・75%・100% から選べます（初期値 75%）。

| 武器 | 弾数 | 特徴 |
| --- | --- | --- |
| SMG | 36 | 連射が最速で足も速い。遠くでは威力が半分まで落ちる |
| AR | 30 | 標準。狙えばばらつきが3割まで減る |
| SR | 5 | 一発が重い。腰だめでは当たらないので、狙って撃つ。対戦では頭に当てると一撃。弾が 160m まで届く（ほかの武器は 80m） |
| LMG | 80 | 弾が多く撃ち続けられる。装填が長く、足が遅く、ばらつく |
| SG | 6 | 8粒の散弾。近距離専用。対戦では近ければ一撃（腰だめで 3m、狙えば 6m まで） |

武器ごとに弾倉は別々で、予備弾は無限です。弾のばらつきはソロと対戦で同じ値です（ソロではタッチ操作向けの狙いの補正が別に働きます）。
- 開始画面で、視点の感度（5段階）、ボタン配置（射撃・装填・跳ぶ・狙う・武器枠1〜5・移動スティックを画面の端まで好きな位置へドラッグ、ひとつずつ大きさを変更、左右入れ替え）、武器の並び（武器枠1〜5のどれにどの武器を置くか。枠を2つ続けて押すと入れ替わる）、射撃中の視点操作（タッチのみ。切にすると射撃ボタンを押したまま指を動かしても視点が動かない）、オート射撃、効果音、ダメージ数字の濃さを変更できます（一時停止中も変更可）。オンラインの対戦モードでは狙いの補正とオート射撃は働かず、弾は武器ごとのばらつきの範囲で照準へ飛び、相手の体（脚・胴・頭）に当たったときだけ命中になります。設定と自己最高得点は端末に保存されます。

知っておくと役に立つこと：

- 階段は歩くだけで上がれます（跳ぶ必要なし）。
- トレーラー・トラック・貨車・漁船は、車体の下の隙間を弾が通ります。足元は撃たれます。
- 金網フェンスは通り抜けられませんが、弾は通ります。
- 網目の床と階段（サイロの高架コンベヤと舷梯）は、上に立てますが弾は通ります。
- 氷の上（聖夜の凍った港）は滑ります。止まりたいときは、早めに手を離すか、島・桟橋・船に上がります。
- 窓は撃ち合えますが、通り抜けはできません。扉や天井の下では、跳んでも頭がつかえます。
- ソロでは、偵察機と突撃機は倉庫のシャッターから中へ入ってきます。重装機と管理棟の中は入れません（窓と扉越しに撃ってきます）。ドローンは北・南・海（東）から現れます。
- 横丁には登れる高い場所がありません。乗れるのはカウンター、ベンチ、ビールケース、植え込みまでで、衝立や屋根には上がれません。
- ソロの横丁では、ドローンは外周の通りに降りてきます。偵察機と突撃機は衝立の隙間を抜け、重装機は衝立の上を越えます。居酒屋と立ち飲みの中まで入ってくるのは突撃機だけです。
- 上屋では、ドローンは壁の高窓の高さから入ってきて、ボスも含めて屋根の下（高さ 8.6m まで）を飛びます。
- ソロでは第20波にボスが出て、その先は5波ごと（25、30、35…）に別の種類のボスが順に出ます（統括機 → 扇撃機 → 衝角機 → 照準機 → 統括機…）。少しずつ硬くなります（体力は第25波で1.25倍、第30波で1.5倍）。倒すと必ず回復が落ちます。
- ボスは4種類。どれも壁より高いところから降りてきて、来るときは警報が鳴って画面の縁が赤く光り、体力の下にボスの名前と体力が出ます。体力が半分を切ると「出力上昇」と出て攻撃が激しくなります。

| ボス | 攻撃（ソロ） | 協力ではこう強くなる | 避けかた |
| --- | --- | --- | --- |
| 統括機 | 5連射（1発 8）。8秒ごとに突撃機を2機放つ | 1発 12。偵察機（赤い目）も2機いっしょに放つ | 放たれた機体を先に落とす |
| 扇撃機 | 弾を扇状に7発（1発 7）。半分を切ると9発を2回、互い違いに | 7発を2回続けて（1発 10.5）。半分を切ると12発を3回 | 物陰に入る |

- ソロで敵を倒したときに回復が落ちる確率は、第1波で 14%（体力 45 未満のときは 38%）。1波進むごとに 0.5 ポイントずつ上がります（第20波で 23.5% ／ 47.5%）。
- アドレスの末尾に `?wave=20` を付けると、その波から始められます（ボスだけ試したいとき用）。

## ルーム（オンライン）

オンラインはすべて**ルーム**で遊びます。ルームは4桁の番号で区別され、1つのルームに8人まで入れます。通信は自前のルームサーバー（`server/`。Cloudflare の無料プランで動きます）を通ります。設定しなくてもソロは遊べます（ルームのボタンが押せないだけです）。

### いまあるルーム

開始画面の左側の「いまあるルーム」に、いま開いているルームがすべて並びます。ルーム番号・モード・マップ・ホストの名前・人数（○/8）・待機中か試合中かが出て、押すとそのルームに入れます（名前が必要です。満員のルームは押せません）。試合中のルームに入った場合は、ルーム画面から空いている枠に入って途中参加できます。

- 一覧はリアルタイムで更新されます（人が入る・出る、モードやマップが変わる、試合が始まる・終わる）。
- 誰もいなくなったルームは一覧から消えます。回線が切れた人の枠は1分取っておくので、全員が回線ごと消えた場合は消えるまで1分15秒ほどかかります。
- まれに、消えたことをサーバー内で知らせ損ねたルームが、最大25分ほど一覧に残ることがあります。押しても「見つかりません」と出るだけです。
- **一覧に出さないルームは作れません。** ルームはすべて、開始画面を開いた人なら誰でも見られて入れます。

### ホームの会話

開始画面（タイトル画面）の左側に「ホームの会話」欄があります。**いま開始画面を開いている人どうし**で話せます（ルームの募集や待ち合わせ用）。

- 送るには名前が必要です（ルームと同じ「名前」欄）。60文字まで、1秒に1通まで。
- 欄の右上に、いま開始画面を開いている人数が出ます。ソロやルームに入ったとき、タブを裏に回したときは接続を切るので、人数から外れます。
- 開いたときに、直近の発言（30件まで・24時間以内）が出ます。それより古いものは消えます。
- ルームサーバーが古いままだと「会話に接続できません」と出ます。`server/` を更新（デプロイし直し）すると使えます。

### 入りかた

1. 開始画面で名前を入れる（10文字まで・必須。端末に保存されます）
2. 1人が「ルームを作る」を押す → 4桁のルーム番号が出て、ルーム画面に入る。番号を伝えるか、「招待リンクをコピー」で送る
3. ほかの人は「ルームに参加」を押し、番号を入れて「入る」（招待リンクから開くと、番号が入った状態になります）
4. ルーム画面で、空いている枠を押して入る。自分の枠をもう一度押すと枠から出る。人が入っている枠と、満員のチームには入れない
5. ホストが「開始」を押すと、枠に入っている全員がそのまま試合に出る。3・2・1 のカウントダウンのあいだは動けず撃てない（対戦ではこのあいだに武器を選べる）。途中から入った人にはカウントダウンはない

**ホスト（ルームを作った人）だけができること**：モード・マップ・勝利条件の変更、「ランダム」、「開始」、「試合を終える」。ほかの人の画面では、これらのボタンは押せないか、出てきません。ホストがルームを出ると、残っている中でいちばん先に入った人がホストを引き継ぎます。ホストの回線が切れたまま10秒ほど戻らないときも、つながっている人に引き継ぎます（10〜25秒後）。

「ランダム」は、ルームにいる全員を混ぜて枠に振り分けます。2チームのモードでは人数がそろうように交互に、2v2v… では2人ずつ組にして入れます。枠より人が多いとき（3v3 に7人以上など）は、あふれた人が待機になります。

| モード | 枠 | 内容 |
| --- | --- | --- |
| 1v1v… | 8 | 個人戦。自分以外は全員が敵 |
| 2v2v… | 2人 × 4チーム | 2人1組のチーム戦 |
| 3v3 | 3人 × 2チーム | チーム戦 |
| 4v4 | 4人 × 2チーム | チーム戦 |
| 協力 | 8 | 全員でドローンの波を迎え撃つ（ソロと同じ敵） |

### 対戦（1v1v…・2v2v…・3v3・4v4）

- 相手を倒すと**体力が 50 回復**します（上限 100）。
- チーム戦では味方の弾は当たりません（すり抜けます）。同じチームは同じ色です。2チームのモードでは、チームごとにマップの反対側から出撃します。
- レーダーには、味方は常に、相手は発砲直後だけ映ります。
- チーム戦と協力では、味方の頭の上にチーム色の点と名前・距離が出ます。壁の向こうにいるときは白抜きの輪になって薄く見え、画面の外や後ろにいるときは画面の端にその方向で出ます。
- 武器は一丁だけです。開始時に選び、倒されたら復帰までの3秒のあいだに選び直せます（選ばなければ同じ武器。パソコンは 1〜5 キー）。戦闘中の武器切替はできません。
- 倒されると3秒後に別の場所で復帰します。倒されたときは、撃った相手の武器と距離、相手の残り体力、その命のあいだに誰からいくつダメージを受けたかが出ます。
- 体力の下に順位表が常に出ます。撃破数の多い順（同数なら被撃破の少ない順）で、自分の行は明るく表示されます。チーム戦ではチームの合計が上に並び、その下に自分の行が出ます。一時停止すると全員分の表が出ます。
- **勝利条件**はホストがルーム画面で選びます。「エンドレス」（ホストが「試合を終える」を押すまで続く）か「キル数」（1〜999 を自由に入力）です。キル数のとき、個人戦はその数に届いた人、チーム戦はチームの合計がその数に届いたチームの勝ちです。決着すると全員の画面に勝者が出て、約2.5秒後に全員ルーム画面に戻り、結果と順位表が出ます。プレイ中の順位表の見出しには「○キル先取」と出ます。
- エンドレスでも、ホストが一時停止画面（またはルーム画面）の「試合を終える」を押せば、全員がルームに戻って順位表が出ます。
- **対戦は最長1時間です。** 始まってから1時間たつと、勝利条件に関係なく「時間切れ」で全員ルームに戻り、そのときの順位が出ます。残り時間はレーダーの下に小さく出て（残り10分を切ると秒まで、5分を切ると色が変わる）、残り10分・5分・1分で知らせが出ます。協力には時間制限はありません。

### 協力

- ソロと同じドローンの波を、全員で迎え撃ちます。**毎波ボスが出ます**。第12波までは1体で、扇撃機 → 衝角機 → 照準機 → 統括機 の順にくり返します。**第13波からは、違う種類のボスがランダムに2体**出ます（体力バーも2本）。ボスの体力は波が進むほど、人数が多いほど高くなります（協力の衝角機はさらに1.2倍）。ボス以外の機数は、ボス1体の波ではふだんの6割、2体の波ではその2/3（ふだんの4割）です。1人増えるごとに1波の機数が5割増え、同時に飛ぶ数も増えます。
- 倒れた人は、その波を誰かが制圧したときに体力満タンで復帰します。全員が倒れたら終わりで、ルームに戻って到達した波と得点が出ます。
- 得点は全員で共通です。順位表は撃墜数です。武器は自由に切り替えられ、狙いの補正とオート射撃もソロと同じく働きます。
- ドローンは1台の端末（試合中でいちばん先に入った人）が動かして、ほかの人に配ります。その人が試合を抜けたり、アプリを裏に回したりすると、1.5秒ほどで次の人が引き継ぎます。
- 離席中（一時停止中・タブを裏に回している間）もドローンは動き続けます。離席中もその場に姿は残りますが、狙われず、撃たれません。

### 共通

- 試合中でも、空いている枠に入って「試合に参加する」を押せば途中から入れます。一時停止画面の「ルームに戻る」で自分だけルームに戻り、同じ試合にまた入り直すこともできます（撃破数は続きから）。
- チャットは、右上の「会話」ボタン（パソコンは Enter か T）で入力欄を開き、40文字までの文を送れます。試合中の全員の画面左上に名前つきで表示され、約9秒で消えます。連続送信は1秒に1通までです。
- 誰が誰を倒したかが画面左上に名前で流れます。
- 試合中は、レーダーの下にルームサーバーまでの往復時間（ピン）が小さく出ます。緑は 80ms 未満、黄は 160ms 未満、赤はそれ以上。3秒ごとに測ります。
- **3分間操作がないと、試合から外れます。** 一時停止中・タブを裏に回している間・ただ立っているだけ、のどれでも数えます。残り30秒で知らせが出ます。枠はそのままなので、ルーム画面の「試合に参加する」で戻れます（撃破数は続きから）。協力で倒れて波の制圧を待っているあいだは数えません。
- **離席しても、その場に残ります。** 一時停止中やタブを裏に回している間も、自分の姿はその場に立ったままで、ほかの人から見えます。対戦では撃たれれば倒されます（倒された場合、復帰は戻ってきてから）。味方の頭の上の名前には「離席」と出ます。
- **回線が切れても・ページを閉じても、1分間はその場に残ります。** ほかの人の画面では、その人は最後に立っていた場所に半透明で残り、味方なら名前に「切断中」と出ます（弾はすり抜けます。撃っても受け取る人がいないため）。ルームはその人の枠と試合の居場所を1分取っておき、回線が切れたときは自動でつなぎ直します。
- **再読み込みしても、ページを閉じて開き直しても、1分以内なら同じ人として同じ枠に戻ります。** 試合中だった場合は、そのまま試合の、最後に立っていた場所に戻ります（体力・武器・撃破数もそのまま）。離席中の画面で止まっているので、「再開する」で続きから。1分を過ぎると枠は空き、その人はルームから外れます。
- 同じブラウザで見分ける印は端末に保存されます。同じブラウザでタブを2つ同時に開くと、2つ目のタブは別の人になります（1台で2人分を試すとき用）。同じ人が二重に入ることはありません（新しい接続が古い接続を置き換え、古いほうは「ほかのタブで入りました」と出てルームを抜けます）。

### ルームサーバーの用意（最初に1回だけ）

`server/` を Cloudflare（Workers と Durable Objects）に置きます。無料プランのままで使えます。

**方法A：GitHub から（パソコンに何も入れなくてよい）**

1. [Cloudflare](https://dash.cloudflare.com) のアカウントを作る
2. **Workers & Pages** → **Create application** → **GitHub** を選び、GitHub と連携して、このリポジトリを選ぶ
3. 設定画面で次のようにして **Save and Deploy**
   - 名前（Worker name）：`pier9-rooms`（`server/wrangler.toml` の `name` と同じにしないと失敗します）
   - Root directory（ルートディレクトリ）：`server`
   - Deploy command：`npx wrangler deploy`（初期値のまま）
   - ブランチ：`main`
4. 終わると `https://pier9-rooms.<あなたのサブドメイン>.workers.dev` という URL が出ます。ブラウザで開いて `pier9 rooms: ok` と出れば動いています
5. `config.js` の `server` にその URL を入れて、コミットしてプッシュする

```js
window.PIER9_NET = {
  server: 'https://pier9-rooms.あなたのサブドメイン.workers.dev'
};
```

以後、`main` の `server/` を変えると自動でデプロイし直されます。画面の表記は Cloudflare 側で変わることがあります。

**方法B：パソコンから（Node.js が必要）**

```sh
cd server
npx wrangler login
npx wrangler deploy
```

最後に表示される URL を、方法Aの5と同じく `config.js` に入れます。手元で試すときは `npx wrangler dev` で `http://127.0.0.1:8787` に立ち上がるので、`server` をその URL にします。

**サーバーを更新するとき**：`server/` が変わったときは、新しいアカウントでログインした状態で、もう一度 `server` フォルダから `npx wrangler deploy` を実行してください（`npx wrangler whoami` でアカウントを確かめてから）。サーバーが古いままでもゲームは動きますが、新しい機能（勝利条件など）は使えず、ルーム画面にその旨が出ます。

以前使っていた Supabase はもう使いません。Supabase のプロジェクトは消してかまいません。

### 無料枠の目安

- Cloudflare の無料プランでは、Durable Objects へのリクエストは1日10万までです（日本時間の朝9時にリセット）。料金ページには「WebSocket で届くメッセージは20通で1リクエストと数える」とあり、サーバーから配る分は数えません。
- いまあるルームの一覧のため、各ルームは中身が変わったとき（人の出入り、モード・マップの変更、試合の開始・終了）と、変化がなくても10分ごとに1回、ホームへ知らせます（1回＝1リクエスト）。10分ごとの分は、ルーム1つが1日開きっぱなしで約144です。
- 開始画面を誰かが開いているあいだ、ホームは1分ごとに見回りをします（1回＝1リクエスト。誰かが1日中開いていれば約1,440）。
- 一覧と会話を開始画面の人へ配る分は、サーバーから送り出すメッセージなので数えられません。
- ホームの会話は、開始画面を開くたびに1リクエスト、発言1通ごとに1回（20通＝1リクエストの数え方なら1/20）です。生存確認の ping は数えられません。
- 試合中は1人が毎秒10通送ります（一時停止中は毎秒2通）。ほかにピンを測る ping が3秒に1通あります（サーバーが部屋を起こさずに返すもの。送る量の3%ほど）。20通＝1リクエストで数えると、8人で1日約7時間、4人で約14時間遊べます。ルーム画面で待っているあいだはほとんど数えられません。
- ただし、この20対1の数え方は料金ページで「請求のための計算」と書かれていて、**無料枠の上限判定にも同じ数え方が使われるかは明記されていません**。もし1通＝1リクエストで数えられると、8人で20分ほどで上限に届きます。最初に遊んだあと、Cloudflare のダッシュボード（Workers & Pages → pier9-rooms）で使用量を確かめてください。
- 上限を超えると、その日はルームに入れなくなります（ソロは遊べます）。

### 知っておくこと

- 当たり判定は撃った側の端末が行い、撃たれた側がそれを信じる方式です。協力のドローンの体力は、ドローンを動かしている端末が持ちます。不正対策はないので、知り合い同士で遊ぶ前提です。
- ルームはすべて「いまあるルーム」に出るので、開始画面を開いた人なら誰でも入れます（8人まで）。
- チャットは保存されず、暗号化や内容のチェックもありません。ルーム番号を知っている人なら誰でも読めます。
- ホームの会話は、ゲームのページを開いた人なら誰でも読み書きできます。直近30件（24時間以内）だけサーバーに残り、内容のチェックも、特定の人を締め出す機能もありません。
- ルームサーバーの URL はページのソースから誰でも読めます。第三者がこのサーバーで無料枠を消費することは防げません。

### js/ の決まり

- ビルドはありません。`index.html` に並べた `<script>` を上から順に読み込みます。モジュール（`import` / `export`）ではない普通のスクリプトなので、どのファイルでも一番外側で宣言した名前は、ほかのすべてのファイルから使えます。そのぶん、同じ名前を2つのファイルで宣言するとエラーになります。
- 関数の外に書いたコード（読み込んだときにすぐ実行される部分）は、自分より上のファイルにあるものしか使えません。関数の中からなら、下のファイルにあるものも使えます（関数が呼ばれるのは全部を読み込んだ後なので）。
- ファイルを足すときは、`index.html` の一覧の、使うものより下に加えます。
- 全部を読み込み終えるまで開始画面のボタンは反応しません（`main.js` が `body` に `ready` を付けるまで。読み込みの途中で押されて、まだ無い関数に届くのを防ぐため）。

### 見た目を作り込むとき

- three.js は r128 を CDN から読み込んでいます（`index.html`）。r128 の追加機能（3D モデルを読む `GLTFLoader`、画面全体に効果をかける `EffectComposer` など）は、`https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/…` にある普通のスクリプト版を three.js の直後に `<script>` で足せば、いまの作りのまま使えます。
- three.js を新しくする場合、この形のまま上げられるのは r147 までです。r148 からは追加機能が、r161 からは本体も `import` で読む形（ES モジュール）しか無いので、`js/` をモジュールに書き直す必要があります（別のファイルから書き換えている変数が 46 あり、モジュールではそのままでは書き換えられないので、ひとまとめにする作業が要ります）。光の強さや色の扱いも途中の版で変わっているので、見た目の調整もやり直しになります。
- 画像・モデル・音のファイルを使い始めると、`index.html` を直接開く方法（`file://`）ではブラウザがそれらを読ませません。手元では `python3 -m http.server` などで開いて `http://localhost:8000` で遊んでください。Vercel ではそのまま動きます。
