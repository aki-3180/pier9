# assets

画像・3D モデル・音のファイルを置く場所です。いまのゲームはファイルを1つも使っていません（模様は canvas に描き、形は箱と円柱の組み合わせ、音は Web Audio で合成）。作り込みでファイルを使い始めるときは、種類ごとに分けて置きます。

| フォルダ | 中身 | 形式の目安 |
| --- | --- | --- |
| `textures/` | 壁・床・コンテナなどの模様 | `.webp` か `.jpg`（透けるものは `.png`）。一辺を 2 の累乗（256・512・1024）にする（古い端末でも three.js が作り直さずにそのまま繰り返し貼れる） |
| `models/` | 銃・ドローン・建物などの形 | `.glb`（three.js の `GLTFLoader` で読む） |
| `audio/` | 効果音・環境音 | `.mp3`（iPhone を含めどこでも鳴る） |

- フォルダは、最初のファイルを置くときに作ってください。
- ファイルを使い始めると `index.html` を直接開く方法（`file://`）では読み込めなくなります。手元では `python3 -m http.server` などで開いてください。
- スマホで遊ぶので、合計の大きさに気をつけてください（読み込みが終わるまで遊べないため）。
